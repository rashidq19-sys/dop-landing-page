## 2. Indexing and technical spot-check — all clean

Every URL in the live `sitemap.xml` was fetched from production and checked for HTTP 200,
page-specific `<title>`, self-referencing canonical, and no `noindex` (canonical agreement is the
soft-404 test — the old failure was sub-pages served as the SPA shell with home's title and
`canonical = /`).

**Result: 37 / 37 URLs pass** (up from 33 in October — four new blog posts, including the
DVSA daily-walkaround guide published 2026-10-26).

- **404 handling — verified live:** `/random-invalid-page-test` returns a real **404** (not a soft 200).

**The site is technically sound. The problem is entirely visibility/authority, not crawlability.**

## 3. Top 3 opportunities

### 1. Get a free Gartner directory listing (GetApp / Capterra / SoftwareAdvice UK)

Still the clearest route in, and this month gave direct proof: **Courio — a UK competitor — is the
only DSP-ops product that surfaced for a UK buyer query, and it surfaced through its SoftwareAdvice UK
listing, not its own site.** One free vendor profile covers all three directories. Use the
fleet / delivery-management category, not "Amazon DSP" (which those sites file as ad-tech).

### 2. Close the brand gap that October flagged

Searching "DSPOps" still finds nothing of ours. The GitHub PRs dropped out this month, but the repo is
still public with no website link, so they can come back.
- Make `rashidq19-sys/dop-landing-page` private, or at minimum set its About → Website to `https://dspops.app`.
- Create the citations that give Google a real "DSPOps" entity: LinkedIn company page, Crunchbase,
  Companies House name match — each linking to dspops.app.

### 3. Copy Hera's play on `dsp rota management`

Hera ranks for this term with a single page explaining how Amazon DSPs run their daily roster — the
rest of the results are NHS rotas and patents, so the bar is low. `/dsp-rota-management` is a product
page; a plain-English blog guide ("How UK Amazon DSPs build the daily rota") linking to it would target
the same informational intent. Same idea for `van inspection app`: the new DVSA walkaround post should
link prominently to `/van-inspection-app`, since no result on that page is Amazon-DSP-specific.
